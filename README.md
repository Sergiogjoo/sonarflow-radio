# Sonarflow Radio

App de radio online con diseño premium y experiencia moderna.

## Características planeadas
- Diseño Material 3 premium (tema oscuro elegante)
- Reproductor de radio con visualización de audio
- Lista de emisoras con búsqueda y favoritos
- Soporte HLS / streams estables
- Interfaz fluida y animaciones
- Notificaciones y controles en segundo plano

## Tecnología
- Kotlin + Jetpack Compose
- Material 3
- Media3 (ExoPlayer)
- Coil para imágenes
